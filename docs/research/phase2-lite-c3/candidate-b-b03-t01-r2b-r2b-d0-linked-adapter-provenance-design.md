## 2. P3-01 mandatory: Source → object → linked binary → Python Adapter attestation

The future **first load** is a separate privileged *research admission decision*, not an effect of CI success. The sequence is immutable:

1. **Source/commit lock (PRE-COMPILE).** Pin exact same-repository reviewed Git commit SHA + Git Tree; verify complete `MANIFEST.sha256`; compare byte SHA256 for every C source, C11 ABI header, build script, future Adapter source, linker script and all compiler inputs. Record compiler executable hash, compiler version, target architecture, SDK/sysroot selection, environment and complete ordered compile + link argv. Reject branch drift, non-reviewed generated source, untrusted build flags, environment linker overrides, ad hoc injected code, or any user PID/PGID/command/path.
2. **Test-only compile (PRE-LINK).** Exact `C3B03_TEST_NO_SIGNAL_STUB=1` in every translation unit, absence/0/2 must fail; compile the **single reviewed candidate**, with a fixed build configuration and no fallback code. Require independently checked object SHA256, symbol tables, relocation entries, architecture machine-code inspection and no OS group-signal reachable path. Previously observed object digests (`57bc222a4523d8d1057f7f1764afea6ce99d717c3f9f0d98aab369042eb5df03` Darwin ARM64, `857ddb7564fe68950a84f15751e1799423e0dfef251b65dcec1b53ccaaf646dc` Linux x86_64) are **historical object evidence**, NOT accepted hashes of any future linked library.
3. **Final link and PRE-LOAD verification.** Only in a **future independently approved compile/link/inspect-only PR**, build a test-only Mach-O `.dylib` on Darwin or ELF `.so` on Linux in a newly created private `0700` test directory. Before *any* dynamic load, freeze SHA256 of the actual final bytes, ELF/Mach-O type, arch/ABI, symbol definitions/imports, weak/alias symbols, every relocation/call/branch target, load commands and dependencies, constructors/initializers, interposers, stack-protector/runtime library paths. Compare against the **independently reviewed and architecture-specific exact allowlists**; any unexpected dynamic dependency, initializer/constructor, PLT/GOT import, indirect call/branch, trap instruction or call target → **STOP/BLOCK before load**. Source grep or an old `.o` hash alone is not enough.
4. **Artifact custody / TOCTOU.** Use an isolated, newly created, owned `0700` directory; `lstat` every path component, reject symlinks/hardlinks and unsafe ancestors, prove regular file, `st_nlink == 1`, exact owner/identity and no outside writer, use exclusive write+atomic finalize and read-only permissions. Calculate the reviewed final library byte SHA by a trusted file descriptor; preserve inode/device and identity until the loader operation. Reject replacement after check, changed path, unexpected symlink or alternate loader search path. Since loading a dynamic library may run initializers *before Python can recheck*, **never rely on a post-load SHA/recheck to compensate for missing pre-load constructor and path controls**.
5. **Python Adapter provenance before first call.** Separately review the exact Python Adapter source and its imports/transitive imports for `ctypes.CDLL`/`dlopen` and any hidden eager load. The Adapter may only load the **previously approved path and exact linked SHA** after the external admission check has approved it; no dynamic path/command, runtime recompile, search-directory fallback or `LD_PRELOAD`/`DYLD_INSERT_LIBRARIES` override. Its `run_no_signal_case` must pass the frozen [12-key Python request](candidate-b-b03-t01-r2b-r1-contract.md) through exact validation into the test C ABI (67 finite fault IDs, nonzero uint64 nonce, ≤3 same-ledger steps, original/attempt eight-field policy) and actually call the reviewed exported C function. A pure-Python response synthesizer, fabricated `c_adapter_dispatches=1`/`real_group_signal_syscalls=0`, nonce echo or module constant is **not C provenance**.
6. **Independent PRE-EXECUTION approval, then separate safe run.** Source/head/tree/build manifest + final platform-specific library SHA, complete symbol/relocation and reachable call graph, custody procedure and reviewed Adapter→C call path must receive fresh independent **Standards/Spec PASS** *before* any future `ctypes`/`dlopen`/C call. The first execution in an isolated, separately gated no-signal workflow may only verify fake C counters and the frozen 172 behavior contracts; never issue a true group signal or claim lawful waitpid, verified FD cleanup, ownership, native calibrated timing or G2 qualification.

**Frozen safety invariant:** `group_kill_authorized=false`. A no-signal test artifact must never be linked with an alternative real-negative-PGID syscall implementation or obtain OS process-group identity. If even one build/mutation variant can reach live `kill`/`killpg`/`syscall`/`svc` or equivalent, the future job MUST stop **before loading it**; no cleanup fallback or authorized-signal flag can override the STOP.

## 3. P3-02 mandatory: exact exports, relocations and control-flow allowlists

**Export names are architecture exact, not substrings.** Candidate C function name is `c3b03_t01_no_signal_candidate`. Darwin/Mach-O C symbol is **exactly** `_c3b03_t01_no_signal_candidate`; Linux/ELF symbol is **exactly** `c3b03_t01_no_signal_candidate`. Require one defined, external, strong text symbol (not weak/indirect/alias/data) and **zero additional exported symbols**, not just `SYMBOL in exported[0]`. Reject `unsafe_c3b03_t01_no_signal_candidate_alias` even when it is the only exported name. `nm -u` must produce zero undefined imports under the chosen fixed linker configuration (or STOP pending independent review of any necessary runtime symbol, never blanket-whitelist the C or dynamic-loader library). The same rule must be applied to the final linked loadable artifact; compiler-generated metadata and loader startup sections are inspected explicitly rather than ignored.

**Relocation and call graph rule:** Dump *all* relocations and dynamic dependencies for the exact reviewed platform artifact. Linux: inspect `readelf -rW`, `readelf -dW`, `readelf -SW`, `nm -g` and `objdump -dr` (or independently vetted equivalent). Darwin ARM64: inspect `otool -rv`/`otool -l`, `nm -g` and `otool -tv` (or vetted `llvm-objdump` equivalent). Reject every unknown relocation target, imported symbol, PLT/GOT entry, unresolved indirect branch, dynamic `dlsym`/`dlopen`, relocation to a non-whitelisted symbol, or executable section with potential trap. The first valid call graph should consist only of reviewed local pure-data helpers and the single exported entry; a `ret` from the function is not an unsafe external call. The later reviewer must validate the **full source-to-final-binary identity** (including compiler, linker, SDK, immutable object and final library SHA) and both **C source-to-final-binary identity** and the exact call target after link, including Mach-O/ELF section layout and stack protector insertion. If the platform tool output cannot be fully parsed or the allowlist cannot be established → **BLOCK**, not SKIP.

**Dynamic initializer rule:** ELF `.preinit_array`, `.init_array`, `DT_INIT`, `DT_NEEDED`; Mach-O `__mod_init_func`, `__interpose`, `LC_LOAD_DYLIB`/`LC_LOAD_WEAK_DYLIB` and similar initializer/dependency constructs are **reviewed-deny by default**. A link that introduces an initializer or a dependency cannot be loaded while classification is UNKNOWN. Loading `.so`/`.dylib` can itself execute code, so the gate must be completed **before** loading.

**P3-02 falsification cases:** exact export PASS; prefix/suffix alias only FAIL; two exports FAIL; weak export FAIL; undefined symbol FAIL; external relocation FAIL; indirect call FAIL; signal/trap opcode FAIL; unexpected dynamic dependency FAIL; init section FAIL; hash mismatch FAIL; alternate platform ABI FAIL. A test-only parse fixture is not a substitute for real macOS/Linux linker output and actual binary inspection.
