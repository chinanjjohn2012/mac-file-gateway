# Phase 2 Lite C1 — descriptor-based native spawn research

**RESEARCH ONLY. NOT G2 QUALIFIED.** Do not import this native helper into Gateway, use it with business directories, enable Multi exec, or deploy it.

## What the experiment checks

An isolated C helper uses Darwin posix_spawn_file_actions_addfchdir_np with an already opened O_NOFOLLOW directory FD. The child must report the original directory dev/inode both for a normal launch and after the test-only directory is renamed and replaced. The helper requests POSIX_SPAWN_SETPGROUP, then uses a stdin barrier to check creation-time PGID == owned child PID before releasing the synthetic Python child. Child PID cleanup is bounded and never sends group signals. The native helper requires a synthetic marker before the rename and only runs inside disposable directories generated by the Python driver.

This tests a possible replacement for the previous /dev/fd directory launcher that failed on macOS with ENOTDIR. It is **not** evidence that real Pipenv, descendant cleanup, PGID reuse, or safe group-signaling behavior works. The original Mac SDK 1.30.0 Q0 failure is historical; release/ms1 currently uses MCP SDK 2.3.0 and is unaffected by this research code.

## Run on native macOS arm64 / Python 3.13+

From a checkout of this branch:

    EVIDENCE=$(mktemp -d)
    python3 tools/research/run_c1_fd_probe.py --evidence-dir "$EVIDENCE"
    echo "c1_probe_exit=$?"

Requires the local macOS developer compiler (cc). No packages, global configuration, Gateway daemon or network access are needed. The runner compiles into disposable private storage, uses only generated directories, prints a sanitized verdict, and optionally saves c1_fd_probe_private.json in the provided private evidence directory without overwriting previous evidence. Do not attach private evidence or real filesystem paths to public PRs.

- Exit 0: BOTH native observations succeeded; decision PARTIAL_NATIVE_OBSERVATION_NOT_G2. **Do not call G2 PASS.**
- Exit 2: Compile, actual cwd, creation-time group identity or owner reap failed; BLOCK.
- Exit 3: Unsupported platform/Python or invalid evidence location; NOT_RUN, never PASS.

Linux CI runs:

    python3 -m pytest -q tests/test_c1_fd_probe.py

Those tests verify parsing, fail-closed platform behavior, synthetic marker, and bounded owner lifetime. Passing them is NOT native validation.
