# V2.0 证据与测试适配规范 — 候选

STATUS: DRAFT / NOT_EFFECTIVE

## 原则
核心规则只规定必须证明什么；此文件规定按受审对象选择怎样证明。适配差异不是降低验收门槛的理由。本候选版**不得替代现行已批准 G01–G08**；当前在途 GitHub PR 仍按原批准规范执行。

## 1. 证据对象分型

| 模式 | 必须绑定与限制 |
| --- | --- |
| COMMITTED_REPOSITORY | 固定 commit/tree/必要文件集合、有效差异、Base 及权威合同版本；不能声称看过开发者未提交工作树 |
| LOCAL_UNCOMMITTED | 真实工作树的 tracked/staged/unstaged/untracked/ignored 的适用源、Manifest/哈希、审查前后变化 |
| MERGED_RESULT | 记录被执行的真实 merge commit/tree 和其父提交/对应来源；与 Head 不相同时明确测试对象、适用范围和不能推出的结论 |
| GENERATED_OR_EXTERNAL | 固定参与执行的生成源码、子模块、LFS、下载制品和依赖内容身份；未固定的输入视为缺口 |
| MIXED | 逐部分提供可核验身份，任一关键部分不完整不得推出整体通过 |

## 2. 证据合同

E1 — 确定代码身份：固定受审代码、必要外部代码/制品、规则和合同版本，且证据可供独立复核。  
E2 — 覆盖实际文件集合：不能从截断的 Diff、单个补丁或口头摘要推断完整集合；必要时核验 Git 对象与内容哈希。  
E3 — 证明执行同一性：真实测试记录必须识别实际运行代码、环境、输入和版本。GitHub 合成 Merge 与 Head 可以是不同树；**分别记录并验证**，不因 SHA 不同自动视为违规，也不把一个测试对象冒充另一个。  
E4 — 执行源污染防护：检查参与编译、导入、加载或运行的未固定输入、untracked/ignored/source-shadow 等适用风险；必要时在执行前采样并保留证据。  
E5 — 核对真实结果：记录原始日志、命令、退出码、RED/FAIL/PASS/SKIP/NOT_RUN 和环境约束；第三方 CI 原始证据适用时可使用，不强制某个 CI 服务。  
E6 — 漂移拒绝：代码、Base、合同、外部制品、实际执行身份漂移时独立评估并重新绑定，不沿用旧 PASS。  
E7 — 审查独立性与范围：B/C 各自独立核验，不依赖开发者自述或另一评审者结论。  
E8 — 安全授权：必要测试不得越过隔离与授权边界；未获授权的高风险操作记录缺口与对 PASS 的影响。

适用矩阵必须由目标的合同和真实调用链决定。某项技术检查确实不适用时需写清理由、依据和影响；**必要证据不能使用 N/A 绕过**。

## 3. 测试风险分级

| 等级 | 例子 | 门禁 |
| --- | --- | --- |
| T0 | 静态检查、只读代码检查、普通离线回归 | 按实际合同执行 |
| T1 | 隔离非破坏性原生/数据库/SDK 测试 | 按合同变化、风险及可验证环境决定 |
| T2 | 隔离资源上的破坏性测试、进程终止、数据清理/回滚 | 只有必要且明确核验目标资源、隔离、恢复与授权才执行 |
| T3 | 真实/共享/生产资源或高影响实验 | 默认不自动执行，必须单独授权 |

**不得因为某测试未重跑就把评审工作自动标记为未完成**。独立标记 NOT_RUN、原因、历史证据的代码/依赖/配置/执行环境适用性及对当前合同/放行的影响。既往 PASS 不自动变为当前快照 PASS；必要的当前验证缺失应为 EVIDENCE_STATUS: INSUFFICIENT 和相应 BLOCKED。

## 4. 与已批准 G01–G08 的兼容和迁移

G01–G08 原批准内容、原 Git Blob、PR #73 的定向设计双 Review 保持不变。G01–G08 属于严格 GitHub 远端证据配置，不是所有项目的默认流程。这里的 E1–E8 是未来 V2 候选抽象，**不能用于绕过当前 G04/G05 的强制约束**。

尤其“Head 与 Merge Tree 可以不同”的新描述属于 **拟议新语义**。现行批准 G04 对合成 Merge Tree 另有严格限制；在用户明确批准兼容性变更、完成双独立设计复审和生效迁移前不得代替旧要求。

## 5. 验收输出

EVIDENCE_PROFILE_ID、EVIDENCE_MODE、EXECUTED_CODE_ID、SOURCE_INTEGRITY、EXECUTION_IDENTITY、EVIDENCE_STATUS、NOT_RUN、HISTORICAL_EVIDENCE_REUSE_DECISION、GAPS_AND_IMPACT、AUTHORIZATION_STATUS；无证据不得写 PASS。
